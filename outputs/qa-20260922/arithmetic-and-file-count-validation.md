## Changes

- Added an exact-cents arithmetic verifier for the narrow `item,quantity,unit_cost,total` CSV layout, including optional final TOTAL. It uses existing successful local-file read results, with no new filesystem reads or permissions. It is activated for edited files when the current request asks to calculate, update, check or verify totals. Copy-only source datasets are excluded.
- Arithmetic discrepancies enter the existing pre-finalization reminder. A correction must be read back completely before the finding clears. Known discrepancies block clean initial completion and produce explicit partial-success reporting if a follow-up ends unresolved.
- File edit/create headers count distinct known target paths, using correlated input paths when result receipts omit the path. Failed edits are excluded from completed counts.
- OpenAI OAuth prompt-cache rejection is remembered per provider instance. The first unsupported-cache response retries without cache controls; later turns skip the rejected controls instead of repeating the failed request. This keeps the fallback local to the affected capability and resets with a new provider instance.
- Shell summaries deduplicate the executor's correlated `tool_call` and command-detail receipt by `toolUseId` and command text, including persisted timeline-v2 events. A single successful shell execution now contributes one command and one tool count.
- Moved the pure action-summary builder out of the React `ActionBlock` component module. Timeline edits no longer invalidate the Fast Refresh boundary or leave the renderer with a stale `buildActionBlockSummary` export.
- Normalized missing or invalid retry-attempt values before applying token decay and timeout decay. A test harness callback that omitted its attempt number previously passed `NaN` to `setTimeout`, producing `TimeoutNaNWarning` and a one-millisecond deadline.
