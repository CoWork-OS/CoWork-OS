# Web Search Plus attribution

This CoWork OS plugin pack adapts the workflow and product direction of
[hermes-web-search-plus](https://github.com/robbyczgw-cla/hermes-web-search-plus),
copyright its contributors and distributed under the MIT License.

The CoWork adaptation uses CoWork OS native web_search and web_fetch tools. It does not bundle
the Hermes Python runtime, provider credentials, or the separately distributed DonSeTch program.
