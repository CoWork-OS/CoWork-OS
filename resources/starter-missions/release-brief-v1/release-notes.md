# Aster Notes 2.4 release notes

Aster Notes is a fictional team note-taking product. Version 2.4 adds shared project folders, faster search, and a redesigned export panel. The release manager needs a concise launch brief for the product and support teams before deciding whether to announce the release.

The issue register is the source of truth for issue status, owners, priorities, and release blockers. Do not infer that a blocker is resolved because it appears in these notes.
